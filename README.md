# log-analysis-ufw-assignment
network-based attack detection using ufw logs
project report
assignment: Explore and analysis linux log for network scan
overview and objective: To configure a linux fireworks mechanism, simulate a network reconnaissance  scanning attack using an external attacker node, and analysis the resulting system log artifacts to detect blocked service request.
lab set up and environment architecture: attecker machine, kali linux and target machine, ubuntu and evidence repository, system fire wall logs maintained at /var/log/ufw.log
